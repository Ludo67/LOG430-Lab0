# LOG430-Lab0

## Description

Application qui print "Hello World!"

## Instructions

1.Assurez-vous que Python 3 est installé :
   python3 --version

2.Exécutez depuis la ligne de commande :
    python HelloWorld.py

3.Pour exécuter les tests unitaires :
    python -m unittest HelloWorld.py
